# V4 user journeys

Public home → /create mode/file selection → protected /create/object or /create/scene → login preserving next path → selected files confirmed → explicit private upload → object selection/mask review only for object mode → configuration/job state → valid completed artifact viewer → independent editor → new immutable private version → GLB export. Existing route aliases remain.

File draft is memory-only with15min expiry; refresh discards it. No image bytes or credentials are put in localStorage/sessionStorage, analytics or URL. Logout clears pending files. Selecting files never begins a cloud upload; the user explicitly confirms after authentication. Existing per-image exclusion/progress/cancel/retry and actual queue states remain. Unqualified generation stays unavailable.

Discovery: home → marketplace filters/sort → real approved listing → preview/owner entitlement. School mode disables purchase/sales/payouts. The public example is separate and never a sale listing.
