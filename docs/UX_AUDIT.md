# V3 UX audit

Baseline: existing artifacts/education-public-desktop.png and hosted wizard screenshots.

Visual: repeated mint cards and feature icons compete with the product; animated sample viewer dominates landing. No mascot identity. Korean headings mix Object/Full Scene English.
Functional/copy: /reconstruct/new is overloaded and /create,/projects,/account aliases are absent. Technical model names leak in landing, wizard,pricing,docs and job event messages. Raw API errors reach users. Keep machine codes internally; centralize display copy.
Missing: no standalone editor or immutable asset versions. Add owner-only editor and a labeled public sample editor; a sample is not user generation.
Preserve: actual signed upload/mask review, RLS/private buckets, GPU queue safety, qualified-vs-disabled status and no-commerce policy.
