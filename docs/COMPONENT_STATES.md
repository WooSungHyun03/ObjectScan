# Component state catalog

Public preview route /create demonstrates the two production-choice entries. /demo/edit demonstrates editor buttons/fields/inspector states. /signup and /login demonstrate form validation. /projects (authenticated) demonstrates skeleton/loading, search empty state, errors and project rows. Upload: empty bear, local selection, signed transport progress/cancel/retry, verified thumbnail, per-image exclusion. Region selection: empty, selected, queued, ready/approved, retry. Buttons: neutral primary, outline, ghost, destructive; disabled must have an adjacent reason. Dialogs use existing Radix focus trapping/escape behavior. This route catalog is the lightweight equivalent to a separate component preview app; it exercises actual shipped components, not disconnected mockups.
