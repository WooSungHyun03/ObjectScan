## 2주 이후 — 시간 제한 연구/작은 확장
- [OS-13](tickets/OS-13.md) P2 / A /2인일: 2~20장 실촬영·보정 카메라 MV 적합성 연구. 1024 4-view OOM, 512 진단만으로 실사용 정합을 증명할 수 없음. 완료는 연구보고서/제한slice이며 품질 성공을 보장하지 않는다.
- [OS-14](tickets/OS-14.md) P2 / B /2인일: 21장 이상 객체 복원 구멍·파편 원인 분리 연구. 실학습과 UV GLB는 있지만 시각 품질 탈락. 완료는 연구보고서/제한slice이며 품질 성공을 보장하지 않는다.
- [OS-15](tickets/OS-15.md) P2 / A /2인일: 장면 전체 Mesh 품질 기준과 파편 재현 연구. 32장 학습·추출은 성공했으나 장면 시각 품질 탈락. 완료는 연구보고서/제한slice이며 품질 성공을 보장하지 않는다.
- [OS-16](tickets/OS-16.md) P2 / B /2인일: UV 보존 face crop 기술 spike. 현재 노드 삭제는 face crop이 아님. 완료는 연구보고서/제한slice이며 품질 성공을 보장하지 않는다.
- [OS-17](tickets/OS-17.md) P2 / A /2인일: 외부 소유 GLB의 검증·비공개 수입·게시 bridge. 현재 local editor import는 가능하나 게시에는 소유 server artifact 필요. 완료는 연구보고서/제한slice이며 품질 성공을 보장하지 않는다.
- [OS-18](tickets/OS-18.md) P2 / B /2인일: 마켓 검색·신고와 판매 원장 탐색 확장. 카테고리·가격 정렬은 있으나 파일/라이선스 탐색과 신고 흐름은 제한. 완료는 연구보고서/제한slice이며 품질 성공을 보장하지 않는다.

## 미완성 기능 포괄 지도
- 촬영 coverage/pose 개선은 OS-13~15 연구에 포함; 진짜 정합 없는 점수는 금지.
- face crop/연결 조각 제거/UV보존 경계는 OS-16 연구. remesh/texture painting/rigging은 별도 요구 검증 전 **미산정·미약속**.
- 외부 import게시 OS-17; multi-format OBJ/STL/USDZ는 GLB의 단위/material/texture 손실 조사2d spike 뒤견적,현 Sprint 제외.
- 고급검색/신고/자기원장 OS-18. 리뷰·위시리스트·추천·팀협업·대용량batch는 사용자수요 미검증; 각후속discovery. 실제판매자송금은Owner계약/법무/정산정책전 금지.
- 계정 전체삭제/법적보관기간·quota상품·요금공식값은 OWN-02 정책후 별도slice. 이번 OS-11은 프로젝트삭제와권리hold만.
- 실사용품질보증/자동scene공개/실결제활성은미승인. 기능이 빠졌다고기존실검증SV/editor/TEST원장을다시구현하지않는다.
