# OS-06 — 결과·편집 버전의 휴대 가능한 Mesh 품질 카드

우선순위 **P1** / 담당 **팀원 B** / **1.5인일** / 난이도 **M** / 불확실성 **중간** / 상태 **Ready after dependencies**

## 문제와 사용자 가치 · 현재 근거
변환·노드 삭제·간소화·버전 저장은 실제 동작. 사용자는 삼각형/UV/텍스처/실측 치수 신뢰도를 함께 비교하기 어렵다.

현재 근거: [현재 상태](../01_CURRENT_STATE_AUDIT.md), [Gap](../03_GAP_AND_UX_AUDIT.md). 코드 탐색 경로: `packages/mesh-editor/src; apps/web/src/components/editor; apps/web/src/components/asset-detail.tsx; apps/web/src/lib/server/files.ts`. 기준 SHA에서 해당 화면/API와 고정 fixture를 먼저 재현하고, 이미 충족한 부분은 보존한다. 신규 결함으로 단정하기 전에 현재 테스트와 비교한다.

현재 editor/mesh-editor.tsx는 이미 삼각형 수·파일 크기·UV/표면 이미지 포함 여부를 표시한다. 새 기본 패널을 만들지 말고 이 값을 재사용한다. 이 티켓의 추가 가치는 **원본/편집 버전 비교, 단위 신뢰 표시와 휴대 가능한 보고서**에 한정한다.

## 구현 범위
원본/편집본 triangle·bytes·UV/texture 유무·단위 미확정 표시; 버전별 metadata와 JSON 보고서 다운로드; 기존 GLB export를 유지.

제외: 이 범위 밖의 전면 재설계, 새로운 모델·외부 API 도입, 운영 DB·DNS·실과금·프로덕션 배포.

## 접근·파일·의존성·충돌
재사용: 현재 Next/React/Zod/Supabase, Three/R3F/glTF-Transform, sharp, 기존 Worker 계약. 라이브러리 선택은 [가능성](../04_DIFFERENTIATION_AND_FEASIBILITY.md)의 기능/버전 제한을 따른다.
파일: `packages/mesh-editor/src; apps/web/src/components/editor; apps/web/src/components/asset-detail.tsx; apps/web/src/lib/server/files.ts`. 선행: OS-01. API 공통 파일 `api.ts`, shared contracts, migrations는 PR 단위 직렬 통합하고 각각 전용 helper로 분리한다. migration 번호는 merge 직전 확인한다.

## API/DB/오류·취소 계약
기존 API path와 schema를 우선 재사용한다. 추가 필드는 additive typed version으로 검증하고 client/server 양쪽에 동일 fixture를 둔다. owner_id는 세션에서 도출하고 입력값을 신뢰하지 않는다. unauthorized=401, foreign/not-found=404, stale/conflict=409, invalid=400/422, retryable unavailable=503을 기존 convention에 맞춘다. timeout은 성공으로 간주하지 않고 서버 상태를 재조회한다. mutation은 idempotent하며 terminal 상태를 역행하지 않는다. 크레딧·결제·파일 권한의 확정 권한은 서버에 둔다.

## 티켓별 구체 계약·재현 fixture
quality metadata는 schema_version=1,byteLength,triangleCount,vertexCount,hasTexcoord0,embeddedTextureBytes,materialCount,unitStatus=unknown|declared,artifactVersionId. 원본과편집본을각각서버검증후저장하고클라이언트값을신뢰하지않는다. 보고서에는signedURL/token없음. 검사중/미지원/UV없음 상태를 정상품질과구분.

## Acceptance Criteria
- Given 고정 fixture와 본인 세션, When 관련 동작을 실행하면, Then 간소화본과 원본 카드 값은 실제 파일을 다시 읽은 수치와 일치한다.
- Given 실측 스케일이 없으 조건, When 해당 사용자/API 경로를 실행하면, Then 실측 스케일이 없으면 길이 정확도나 방수형을 보증하지 않고 미확정으로 표시한다.
- Given 고정 fixture와 본인 세션, When 관련 동작을 실행하면, Then 외부 참조·과도한 텍스처 입력은 기존 예산 내 거부되고 다른 사용자의 버전을 열지 못한다.

## 검증 명령과 제출 증거
`npm ci`, `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`를 실행한다. Python 변경은 `cd gpu-worker && .venv/bin/python -m pytest tests`(가상환경 경로는 doctor로 확인)를 추가한다. E2E는 `npx playwright test`이며 기본 포트3000과 `NEXT_PUBLIC_APP_URL`을 맞춘다. 기존 실행 서버3010을 쓸 때는 `npx playwright test --config artifacts/launch-v5/playwright.release.config.ts`와 APP_URL3010을 함께 사용한다. 선택 suite만 통과하고 전체 통과로 보고하지 않는다.

각 AC의 성공/실패 fixture, 다른 계정 권한 거부, 요청 재전송을 자동화하고 `artifacts/OS-06/`에 명령·exit code·SHA·redacted 로그를 남긴다. UI는 360/768/1440px 실제 Chromium 캡처와 키보드/axe 검수를 제출한다. 실제 GPU 결과와 mock 결과를 분리한다. 실제 GPU가 필요하지만 접근할 수 없으면 mock 통과와 실GPU 미검증을 따로 보고한다.
