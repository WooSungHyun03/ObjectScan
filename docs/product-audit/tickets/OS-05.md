# OS-05 — 단일 이미지 GPU 품질·메모리 회귀 기준 수립

우선순위 **P0** / 담당 **팀원 A** / **1.5인일** / 난이도 **L** / 불확실성 **높음** / 상태 **Ready after dependencies**

## 문제와 사용자 가치 · 현재 근거
실제 SV 1건의 textured GLB는 통과했지만 다양한 입력의 성공률·품질은 미측정. 16GB에서 MV는 OOM을 경험했다.

현재 근거: [현재 상태](../01_CURRENT_STATE_AUDIT.md), [Gap](../03_GAP_AND_UX_AUDIT.md). 코드 탐색 경로: `gpu-worker/models.lock.json; gpu-worker/objectscan_worker/reconstruct_adapter.py; gpu-worker/tests; scripts; docs/validation`. 기준 SHA에서 해당 화면/API와 고정 fixture를 먼저 재현하고, 이미 충족한 부분은 보존한다. 신규 결함으로 단정하기 전에 현재 테스트와 비교한다.

## 구현 범위
권리 확인된 고정 3개 단일 이미지 데이터셋으로 local GPU 직렬 timebox; UV/texture/VRAM/시간/시각 평가 저장; OOM·취소 복구 fixture; 실패도 결과로 보고하고 활성 범위 확대 금지.

제외: 이 범위 밖의 전면 재설계, 새로운 모델·외부 API 도입, 운영 DB·DNS·실과금·프로덕션 배포.

## 접근·파일·의존성·충돌
재사용: 현재 Next/React/Zod/Supabase, Three/R3F/glTF-Transform, sharp, 기존 Worker 계약. 라이브러리 선택은 [가능성](../04_DIFFERENTIATION_AND_FEASIBILITY.md)의 기능/버전 제한을 따른다.
파일: `gpu-worker/models.lock.json; gpu-worker/objectscan_worker/reconstruct_adapter.py; gpu-worker/tests; scripts; docs/validation`. 선행: OS-01. API 공통 파일 `api.ts`, shared contracts, migrations는 PR 단위 직렬 통합하고 각각 전용 helper로 분리한다. migration 번호는 merge 직전 확인한다.

## API/DB/오류·취소 계약
기존 API path와 schema를 우선 재사용한다. 추가 필드는 additive typed version으로 검증하고 client/server 양쪽에 동일 fixture를 둔다. owner_id는 세션에서 도출하고 입력값을 신뢰하지 않는다. unauthorized=401, foreign/not-found=404, stale/conflict=409, invalid=400/422, retryable unavailable=503을 기존 convention에 맞춘다. timeout은 성공으로 간주하지 않고 서버 상태를 재조회한다. mutation은 idempotent하며 terminal 상태를 역행하지 않는다. 크레딧·결제·파일 권한의 확정 권한은 서버에 둔다.

## 티켓별 구체 계약·재현 fixture
manifest에 source/model/checkpoint hash, input hash, elapsed_seconds, sampled_descendant_peak_mib, output byte/triangles/uv/texture, timeout/exit/errorCode를 기록. 데이터는 불투명 textured 소품·복잡 배경 단일대상·얇거나반사재질 실패후보 각1개. 3개×1run이며 통계적 성공률 주장 금지. 총GPU실행6시간 상한(인일과별개 경과시간), timeout시추가학습없이실패기록. QA루브릭은 silhouette/앞뒤왜곡/texture seam 각0~2의주관평가로표기.

## Acceptance Criteria
- Given 고정 fixture와 본인 세션, When 관련 동작을 실행하면, Then 3개 입력 각각 실행 결과와 실패 사유·자식 프로세스 peak VRAM·시간을 남긴다.
- Given 고정 fixture와 본인 세션, When 관련 동작을 실행하면, Then UV 없는 GLB나 텍스처 누락은 파일 존재와 무관하게 실패 처리한다.
- Given 고정 fixture와 본인 세션, When 관련 동작을 실행하면, Then 강제 취소/OOM 후 다음 작업이 실행되며 중복 환급이 없고 GPU 슬롯은 1개다.

## 검증 명령과 제출 증거
`npm ci`, `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`를 실행한다. Python 변경은 `cd gpu-worker && .venv/bin/python -m pytest tests`(가상환경 경로는 doctor로 확인)를 추가한다. E2E는 `npx playwright test`이며 기본 포트3000과 `NEXT_PUBLIC_APP_URL`을 맞춘다. 기존 실행 서버3010을 쓸 때는 `npx playwright test --config artifacts/launch-v5/playwright.release.config.ts`와 APP_URL3010을 함께 사용한다. 선택 suite만 통과하고 전체 통과로 보고하지 않는다.

각 AC의 성공/실패 fixture, 다른 계정 권한 거부, 요청 재전송을 자동화하고 `artifacts/OS-05/`에 명령·exit code·SHA·redacted 로그를 남긴다. UI는 360/768/1440px 실제 Chromium 캡처와 키보드/axe 검수를 제출한다. 실제 GPU 결과와 mock 결과를 분리한다. 실제 GPU가 필요하지만 접근할 수 없으면 mock 통과와 실GPU 미검증을 따로 보고한다.

## Definition of Done · 위험 · Rollback
모든 AC와 관련 회귀가 통과하고 코드/문서/계약이 일치해야 완료다. 리뷰어는 다른 팀원. 실패·보류를 완료로 바꾸지 않는다. migration은 additive하며 로컬 upgrade 검증을 포함하고 원장 파괴적 down migration은 금지한다. UI/새 경로 feature gate로 되돌릴 수 있어야 하며 기존 데이터·private storage·원본 GLB·작업 큐를 보존한다. 실제 활성화는 Owner 승인 대상이다.
