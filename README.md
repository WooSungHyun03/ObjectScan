# ObjectScan v2

Independent Next.js + Supabase + Vercel application with a separate outbound GPU worker. Object Mesh: Pixal3D for 1–20 uploaded images, Object-Aware Loss for 21+. Full Scene Mesh: Gaussian Wrapping. All final outputs require geometry, UV and nonempty embedded baseColor texture.

Read CODEX_MASTER_PROMPT.md, AGENTS.md and docs/TASKS.md. Model code is pinned and audited in docs/MODEL_AUDIT.md. REAL_GPU_VALIDATED is false until genuine model smoke evidence exists. Never enable paid reconstruction on mock evidence.
